# MAX Messenger — GREEN-API

Небольшой React + TypeScript клиент для тестового задания. Поддерживает текстовые сообщения, создание чатов, проверку подключения GREEN-API и получение входящих уведомлений через HTTP API.

## Требования

- Node.js 20 или новее
- Аккаунт GREEN-API и настроенный инстанс для MAX
- Доступ к API-хосту, `idInstance` и `apiTokenInstance`

## Запуск локально

```bash
npm install
npm run dev
```

Откройте адрес, который выведет Vite (обычно `http://localhost:5173`).

Для проверки production-сборки:

```bash
npm run build
npm run preview
```

## Настройка

1. Откройте **Настройки интеграции**.
2. Укажите API URL вашего инстанса (значение `apiUrl` из кабинета GREEN-API; значение по умолчанию — `https://api.green-api.com`).
3. Введите `idInstance` и `apiTokenInstance`.
4. Нажмите **Проверить подключение**.
5. Создайте чат, указав номер телефона или идентификатор чата, который ожидает ваш инстанс MAX.
6. Напишите текст и нажмите кнопку отправки.

Настройки и локальная история переписки сохраняются в `localStorage` этого браузера. Токен не отправляется в сторонние сервисы, кроме выбранного API-хоста. Для публичного production-приложения следует вынести секретный токен на сервер.

## Получение сообщений

Приложение опрашивает `receiveNotification` примерно каждые 2.5 секунды и удаляет обработанные уведомления через `deleteNotification`. Входящие текстовые уведомления добавляются в соответствующий чат.

Форматы уведомлений и идентификаторов чатов могут различаться в зависимости от версии API и типа инстанса. Если конкретный инстанс возвращает иной формат, адаптируйте парсер в `src/App.tsx`.

## Примечания

- Интеграция работает только при наличии действующего инстанса и разрешённого доступа к API.
- Для MAX используйте именно API URL и формат `chatId`, указанные в документации/кабинете GREEN-API для вашего инстанса.
- Браузер может блокировать запросы из-за CORS. Если это происходит, используйте небольшой backend-прокси и не помещайте токен в публичный frontend.
- В текущем интерфейсе предусмотрены только текстовые сообщения, как требует тестовое задание.
